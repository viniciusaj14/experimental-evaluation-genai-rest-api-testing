# GitHub Copilot Condition

## Interaction protocol template

Before data collection, freeze the task prompt, supplied context, permitted Copilot features, interaction rules, stopping criteria, and rules for accepting or editing suggestions.

## Record

- run identifier;
- exact initial prompt and context;
- tool identifier and version actually observed;
- prompts or instructions submitted during the run;
- suggestions accepted, rejected, or edited where collection is permitted;
- start and stop timestamps;
- resulting artifact commit;
- deviations and manual interventions.
