# Research Questions

The following questions are provisional and must be finalized before data collection.

## RQ1 — Functional outcomes

How do REST API test suites produced manually, with GitHub Copilot, and with ChatGPT compare under predefined functional-correctness and test-effectiveness measures?

## RQ2 — Development effort

How does measured development effort differ among the three development conditions under equivalent tasks and stopping rules?

## RQ3 — Quality and maintainability

How do the resulting test suites compare under predefined, independently assessed code-quality and maintainability measures?

## RQ4 — Execution characteristics

How do the resulting test suites compare in predefined execution characteristics such as duration and outcome stability?

These questions do not imply expected outcomes. Associated hypotheses, measures, and analysis procedures have not yet been finalized.
