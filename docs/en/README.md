# English scientific documentation status

The authoritative methodology-related documentation for this study is maintained in Brazilian Portuguese under [`docs/pt-BR/`](../pt-BR/), consistently with the USP/ESALQ capstone text.

The repository distinguishes a completed preliminary pilot using an unidentified public vehicle-domain REST API from a future final controlled experiment using Swagger Petstore OpenAPI 3. Unless explicitly identified as pilot material, future-oriented documentation refers to the final experiment, which has not yet been executed.

Full English translations will be created only after the experimental protocol and its evaluation instruments are frozen. Until then, unfinished scientific documents will not be duplicated across languages because parallel drafts could diverge.

The root [`README.md`](../../README.md) provides the English repository overview, and [`README.pt-BR.md`](../../README.pt-BR.md) provides the Brazilian Portuguese overview.
