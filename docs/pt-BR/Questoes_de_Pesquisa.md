# Questões de Pesquisa

## Questão principal

**QP:** Como o desenvolvimento manual, o GitHub Copilot e o ChatGPT se comparam em termos de produtividade e qualidade na automação de testes de API REST utilizando Behavior-Driven Development (BDD)?

## Questões auxiliares

**QA1 — Produtividade:** Como as três abordagens se comparam quanto ao tempo de desenvolvimento e ao retrabalho necessários para implementar os mesmos cinco cenários de teste?

**QA2 — Qualidade:** Como as três abordagens se comparam quanto à cobertura das cinquenta verificações de validação, ao reúso de código, à aderência ao BDD e à qualidade estrutural?

As questões orientam uma comparação descritiva e não antecipam resultados. Nenhuma métrica adicional deve ser introduzida sem alteração explícita e justificada do protocolo.
